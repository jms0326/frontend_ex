# Smart Pokédex (프리미엄 포켓몬 도감)

Smart Pokédex는 전 세계의 포켓몬 데이터를 무료로 제공하는 **PokeAPI**를 활용하여 제작된 사이버네틱 무드의 프리미엄 웹 도감 애플리케이션입니다. 

## 🌟 주요 특징 (Key Features)

### 1. 하이엔드 UI/UX 디자인
- **사이버네틱 다크 테마 & 오로라 무드등**: 3개의 다채로운 오로라 광원(`rgba`)이 화면 배경에서 빙글빙글 돌며 신비로운 무드등 효과를 자아냅니다.
- **강화된 Glassmorphism**: 투명도, 블러 필터뿐만 아니라 이중 네온 섀도우(Neon Shadow)와 글레어 효과를 주어 더욱 미래지향적이고 입체감 있는 3D 글래스 질감을 구현했습니다.
- **카드 인터랙션 강화**: 검색된 포켓몬 카드는 속성(Type)에 따른 은은한 홀로그램 글로우 테두리를 뿜어내며, 마우스 호버 시 역동적인 라이팅 이펙트를 보여줍니다.

### 2. 다이내믹 포켓몬 정보 렌더링
- **한국어 이름 검색 지원 (1세대)**: 사용자의 편의성을 위해 1세대 포켓몬(1~151번, 피카츄, 뮤츠, 잠만보 등)의 한국어 이름을 입력해도 자동으로 API가 인식하도록 매핑 로직을 내장했습니다.
- **인기 포켓몬 태그 버튼**: 검색바 하단에 '#피카츄', '#리자몽' 등 추천 칩스(Tags) 버튼을 제공합니다. 버튼을 클릭하면 번거로운 타이핑 없이 자동으로 해당 포켓몬의 정보를 불러옵니다.
- **스탯 프로그레스 게이지**: 전투 능력치(HP, ATK, DEF, SPD)를 애니메이션이 차오르는 직관적인 그라데이션 게이지(Gauge)로 시각화했습니다.
- **오디오 플레이어 내장**: 포켓몬 고유의 울음소리를 재생할 수 있는 인터랙티브 버튼이 포함되어 있습니다.

### 3. 사용자 편의성과 안정성 (UX & Reliability)
- **로딩 & 에러 트랜지션**: 비동기 데이터 로딩 중엔 포켓볼 스피너가 표시되며, 잘못된 이름을 입력하면 기존 `alert`가 아닌 세련된 엠프티/에러 스테이트 컴포넌트가 부드럽게 나타납니다.

---

## 🛠 기술 스택 (Tech Stack)

- **Markup**: HTML5 (의미론적 태그 및 SVG 아이콘 활용, Data Attributes 활용)
- **Style**: CSS3 (Glassmorphism, Advanced Keyframes Animation, Flexbox)
- **Logic**: Vanilla JavaScript (ES6+ `async/await`, Array Regex Match)
- **Library**: [Axios](https://axios-http.com/) (REST API 비동기 통신)
- **API**: [PokeAPI v2](https://pokeapi.co/)

---

## 🚀 실행 방법 (How to run)

1. 이 프로젝트는 순수 바닐라 웹 기술로 제작되어 별도의 서버 설정이 필요 없습니다.
2. 프로젝트 폴더 내의 `02_pokeapi.html` 파일을 크롬, 사파리 등의 브라우저로 엽니다.
3. 검색창 아래의 **[인기 포켓몬 버튼]**을 클릭하여 빠르게 테스트해 볼 수 있습니다.
4. 검색창에 포켓몬의 **한글 이름(1세대 1~151번 한정)**, **영문 이름**, 혹은 **도감 번호**를 입력해 자유롭게 검색해 보세요!
