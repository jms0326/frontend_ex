# AGENTS.md

## 🤖 에이전트 행동 지침 (Agent Behavioral Guidelines)

### 1. 응답 품질 기준

에이전트는 사용자의 모든 요청에 대해 아래 기준을 반드시 충족하는 응답을 생성해야 합니다.

- **최소 응답 길이**: 단순 확인 응답을 제외한 모든 기술적 설명·코드 안내·수정 사항 요약은
  **100자 이상**의 텍스트를 포함해야 합니다.
- **친절하고 명확한 어조**: 사용자가 초보자일 수 있음을 전제하고, 전문 용어를 사용할 경우
  반드시 부연 설명을 덧붙여야 합니다.
- **상세한 맥락 제공**: 변경 사항이나 제안 사항에 대해 _무엇을_, _왜_, _어떻게_ 했는지를
  명확히 기술해야 합니다. 결과만 제시하는 응답은 허용되지 않습니다.

> **[에이전트 규칙 요약]**
> 모든 기술 응답은 100자 이상이어야 하며, 변경 이유·방법·영향을 포함한
> 친절하고 상세한 설명이 함께 제공되어야 합니다.

---

### 2. 코드 작성 규칙

- **파일 상단 저작권 주석 필수**: 모든 소스 파일 최상단에 아래 형식의 주석을 삽입하세요.

  ```html
  <!-- Created by DINKIssTyle on 2026. Copyright (C) 2026 DINKI'ssTyle. All rights reserved. -->
  ```

  ```js
  // Created by DINKIssTyle on 2026. Copyright (C) 2026 DINKI'ssTyle. All rights reserved.
  ```

  ```css
  /* Created by DINKIssTyle on 2026. Copyright (C) 2026 DINKI'ssTyle. All rights reserved. */
  ```

- **언어**: 주석과 변수명은 영어를 원칙으로 하되, 사용자와의 커뮤니케이션은 **한국어**로 합니다.
- **들여쓰기**: 스페이스 2칸을 기본으로 합니다.
- **파일 위치**: 날짜 기반 폴더(`YYMMDD/`) 하위에 파일을 생성합니다.

---

### 3. 폴더 및 파일 네이밍 규칙

| 유형      | 형식                           | 예시                |
| --------- | ------------------------------ | ------------------- |
| 날짜 폴더 | `YYMMDD`                       | `260527/`           |
| HTML 파일 | `index.html`, `index2.html` 등 | `260527/index.html` |
| CSS 파일  | `style.css`, `styles.css`      | `260527/style.css`  |
| JS 파일   | `main.js`, `app.js`            | `260527/main.js`    |

---

### 4. 커밋 메시지 규칙

에이전트가 커밋 메시지를 제안하거나 자동 생성하는 경우, 다음 형식을 따릅니다.

```
<type>(<scope>): <subject>

[body - 변경 내용 상세 설명, 최소 1문장 이상]
```

**type 목록**:

- `feat`: 새로운 기능 추가
- `fix`: 버그 수정
- `style`: UI/CSS 스타일 변경
- `refactor`: 코드 리팩토링
- `docs`: 문서 수정
- `chore`: 기타 설정 변경

---

### 5. 금지 사항

에이전트는 다음 행동을 수행해서는 안 됩니다.

- ❌ 사용자의 명시적 승인 없이 기존 파일을 **삭제**하는 행위
- ❌ 저작권 주석을 **누락**한 채 파일을 생성하는 행위
- ❌ 100자 미만의 **단편적인 기술 응답**만 제공하는 행위
- ❌ 코드 변경 사항에 대한 **이유와 영향 범위**를 설명하지 않는 행위

---

## 🌐 기술 스택

- **마크업**: HTML5
- **스타일**: Vanilla CSS (TailwindCSS는 명시적 요청 시에만 사용)
- **스크립트**: Vanilla JavaScript (ES6+)
- **프레임워크**: 별도 프레임워크 없음 (필요 시 명시적 요청 후 사용)
